# Visual QA

WordGarden has a distinct botanical-museum identity: cream/lavender grounds, coral/blue accents, editorial typography and deterministic SVG specimens. Plant form is derived from record metadata and does not claim cultural authenticity.

Chrome checks at 1440, 768, 375 and 320 pixels found no overflow or clipping. Detail and collections remained usable, keyboard activation worked where the record loaded, reduced motion was respected, and mobile navigation remained accessible.

Screenshots: [desktop](screenshots/wordgarden-desktop.png) and [mobile](screenshots/wordgarden-mobile.png).

The production bundle is approximately 183 KB gzip JavaScript and 5 KB gzip CSS, within the initial compressed-JS target. Full lab LCP/INP/CLS tracing was unavailable; these are bundle and functional results, not fabricated Core Web Vitals.
